# Security checklist | مراجعة الأمان

Status: **UNREVIEWED** (a planning template, not a security certificate)

- [ ] No secrets in source control
- [ ] Inputs validated and dangerous output encoded
- [ ] Authentication/authorization reviewed if users/accounts exist
- [ ] Sensitive information minimized and privacy explained
- [ ] Dependencies reviewed / scanner used if relevant
- [ ] Automated tests pass (with command/evidence)
- [ ] Browser flows manually or automatically reviewed
- [ ] All known findings and residual risks reported
- [ ] Public deployment separately approved

Report scanner/tool, date, outcome, and limitations rather than merely checking boxes.
