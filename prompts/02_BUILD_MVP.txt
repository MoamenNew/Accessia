أنا راجعت خطة الـ MVP الموجودة في docs/ ووافقّت عليها بعبارة: أوافق على الخطة.

ابدأ بناء الـ MVP المتفق عليه فقط، مرحلة مرحلة:
- ابدأ بأبسط architecture مناسبة. ما تضيفش features أو خدمات مش اتفقنا عليها.
- بعد كل خطوة شغّل الاختبارات المتاحة واكتب نتيجة حقيقية (PASS/FAIL/NOT RUN).
- سجّل التقدم في docs/BUILD_LOG.md.
- استخدم بيانات تجريبية فقط، وممنوع تحط API keys أو كلمات سر في الكود أو الـ logs.
- لو احتجت اشتراك مدفوع، حساب خارجي، تغيير مدمر، نشر عام، أو وصول لبيانات حساسة: قف واستأذنني بشكل واضح الأول.
- عند نهاية كل مرحلة وضحلي بالعامية المصرية: اتبنى إيه، أجربه إزاي، وإيه اللي ناقص.
